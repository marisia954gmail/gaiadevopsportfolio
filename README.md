# Gaia DevOps Portfolio

A personal DevOps portfolio website built with plain HTML and CSS.

## Contents

| File | Purpose |
|------|---------|
| `index.html` | Main portfolio page |
| `style.css` | Stylesheet (dark GitHub-inspired theme) |

## Sections

- **Hero** – Introduction and call-to-action
- **About** – Bio and key stats
- **Skills & Tools** – Cloud, CI/CD, containers, IaC, observability, security
- **Projects** – Featured DevOps projects
- **Experience** – Career timeline
- **Contact** – Links to email, GitHub, LinkedIn

## Running locally

Just open `index.html` in any browser — no build step required.
